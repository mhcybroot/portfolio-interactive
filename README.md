# ⚡ Mahmudul Hasan — Interactive Developer Portfolio & Systems Hub

An interactive, high-performance **Developer Portfolio & Systems Engineering Hub** built with **React 19, Vite, Three.js, Framer Motion, and Tailwind CSS v4**.

Designed to showcase real production systems, concurrent backends (Java 21 Spring Boot, Rust 2024 Axum), IoT hardware protocols (ZKTeco ADMS, Frigate AI NVR, RTSP CCTV), and live commercial client platforms.

---

## 🌟 Key Features

1. **3D Cyber-Dark Canvas:** High-performance particle constellation with interactive ambient lighting.
2. **Interactive Developer CLI (`InteractiveTerminal.jsx`):** Built-in retro-modern terminal supporting real commands (`help`, `cat architecture.md`, `ls repos`, `git clone <repo>`, `status --live`, `download cv`).
3. **Edge-to-Cloud System Architecture Visualizer (`ArchitectureFlow.jsx`):** Animated multi-stage diagram showing the end-to-end edge hardware to cloud database pipeline.
4. **Deep GitHub Repository Explorer (`GitHubVisualizer.jsx`):** Verified repository cards with slide-over codebase architecture drawers, verified service trees, and 1-click clone widgets.
5. **Live Production Browser Mockups (`LiveDeployments.jsx`):** Interactive desktop browser frames for live commercial websites:
   - [skylinkltd.ai](https://skylinkltd.ai/) *(React, GSAP Motion, Tailwind)*
   - [finaraprosolutions.com](https://www.finaraprosolutions.com/) *(React 19, Three.js 3D)*
   - [homesyncllc.org](https://homesyncllc.org/) *(React 19, 3D Canvas)*
   - [dreamzonebuilders.com](https://dreamzonebuilders.com/) *(React, Base UI, Tailwind)*
6. **Polyglot Codebase Matrix (`PolyglotMatrix.jsx`):** Visual code distribution across Rust 2024, Java 21, TypeScript/React, Dart/Flutter, and PostgreSQL.
7. **1-Click CV Downloads:** Instant PDF and Word (`.docx`) download triggers embedded in the navigation bar and preview modal.

---

## 🛠 Tech Stack

- **Frontend Core:** React 19, Vite 6, JavaScript (ES6+)
- **Styling & UI:** Tailwind CSS, Lucide React, Glassmorphism CSS
- **3D & Motion:** Three.js, Framer Motion, HTML5 Canvas
- **Documents:** Bundled `MAHMUDUL_HASAN_CV.pdf` & `MAHMUDUL_HASAN_CV.docx`

## 🚀 Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/mhcybroot/portfolio-interactive.git

# 2. Navigate into the directory
cd portfolio-interactive

# 3. Install dependencies
npm install

# 4. Start the local development server
npm run dev
```

Visit `http://localhost:3000` to explore the interactive portfolio.

---

## 📦 Production Build & Deployment

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```

### Instant Deployment:
- **Vercel / Netlify:** Connect this GitHub repository and deploy with default build settings (`npm run build` with output directory `dist`).
